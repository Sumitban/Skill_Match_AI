Role Title - Data Scientist Intern

Required skill- 
    * Programming Language : Python
    * Data Manipulation : Pandas, Numpy
    * Data Visualization : Matplotlib, Seaborn
    * Hands on experience with Sklearn
    * Decent understanding of ML Algo(Linear Regression, KNN, XGboost , LightGbm, Catboost, DecisionTrees, Random Forest, Logistic Regression, SVM)
    * Data Scraping : Crawler, Beautiful Soup

Job Description-
    * Cleaning and preprocessing large dataset
    * Confortable with working with pipelines
    * Collect data from various sources using data scraping
    * Collaborate with team to data solution with business needs

Good to Have Skill-
    * Basic understanding of the mlops
    * Basic knowledge of the deep learning like CNN, RNN
    * Decent hands on experience with fastAPI

Strong Signals

        * Have 2-3 projects in resume
        * Project description contains the words like feature Engineering , data lekage , cross validation and evaluation metrices . 
        (for example Built a churn prediction model, handled class imbalance using SMOTE, evaluated using ROC-AUC.)
        * Project descriptio contains the accuracy percentage 
        (for example Built a churn prediction model which is able to predict the churn with the accuracy of 98 percent)

    # Github
        * Contains the Project mentioned in the resume
        * Commit history spread over the time
        * Project Repos contains the read_me file with proper explaination of the problem statement , dataset used , approach and result
        * Project containing clean pipeline with proper EDA, Data Cleaning and Data Visualization

    #Linkedin
        * Role titles that match trajectory (Student → DS Intern → Project work)
        * Skills overlapping with resume + GitHub
        * Timeline consistency (no random jumps)

Weak Signals
    # Resume
        * No or only one project in the Resume.
        * Using common keywords in the project description
        (for example Trained the model using sklearn library)
        * Using Non Technical keywords in skill Section 
        (like AI, leadership, Hardworking)
        * No metrices used in the project Description
        * Absence of the project Description

        * Not Contains the project mentioned in the Resume.
